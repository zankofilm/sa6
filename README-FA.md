# مدرسه‌یار — سورس اندروید V1.6

این سورس برای ساخت APK دانش‌آموز مدرسه‌یار در GitHub Actions آماده شده و نسبت به V1.5 فقط ایراد پوشانده‌شدن دکمه ارسال نهایی در آزمون را رفع می‌کند. طراحی دخترانه V1.2، منوها و قفل اثر انگشت V1.3 و تغییرات V1.4 و V1.5 حفظ شده‌اند. امکانات چت/آزمون به وب موجود متصل‌اند؛ اعلان Push واقعی همچنان به تنظیم Firebase و سرور نیاز دارد.

برای راهنمای نصب و آزمایش به `docs/CHANGELOG-ANDROID-V1.6-FA.md` مراجعه کنید. پچ سایت یا سرور نیست.

در GitHub مخزن فعلی را با پوشه‌های پروژه به‌روزرسانی و `Build Android APK` را اجرا کنید. پیش از حذف APK قبلی، مراقب پاسخ‌های ذخیره‌شده و ارسال‌نشده باشید.
